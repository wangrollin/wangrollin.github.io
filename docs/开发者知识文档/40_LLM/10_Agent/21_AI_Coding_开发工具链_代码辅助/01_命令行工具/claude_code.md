
## 安装

**sh 方式（开梯子）**
curl -fsSL https://claude.ai/install.sh | bash

**brew方式**
brew install --cask claude-code

**npm方式**
npm install -g @anthropic-ai/claude-code

claude -v

## 快捷启动方式

alias claude-go='cd ~/codebase/my_project/claude-playgroud && claude'
alias cg='cd ~/codebase/my_project/claude-playgroud && claude'
