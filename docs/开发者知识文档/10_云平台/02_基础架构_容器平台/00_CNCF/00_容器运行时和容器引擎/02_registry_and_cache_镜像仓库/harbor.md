  市场占有率

  - Quay — Sysdig 调研显示企业客户中占 24%，主要因为是 OpenShift 默认仓库，Red Hat
  企业客户群庞大
  - Harbor — GitHub stars
  遥遥领先（28k），自建仓库领域使用最广。知名用户：CERN、中国移动、京东、OVHcloud。SUSE
  也将其作为"SUSE Private Registry"发行
  - Distribution — Docker Hub 拉取量 17.4 亿次，是底层引擎（Harbor、GHCR、GitLab Registry
  都基于它构建），渗透率实际最高，但用户感知不到
  - Dragonfly — 蚂蚁集团（1万+ K8s
  节点）、阿里巴巴、字节跳动、滴滴、快手等在用，日支撑数千万容器启动，P2P 加速节省 90% 带宽
  - Zot — 最年轻，尚无公开采用数据，定位边缘/IoT/气隙环境

  社区活跃度判断

  - 最活跃开发：Quay（近4周 90 次提交）、Distribution（63 次）
  - 生态最大：Harbor（659+ 贡献公司，VMware/Broadcom 贡献约 72% 代码）
  - 增长最快：Dragonfly（加入 CNCF 后贡献者增长 500%，2025年10月毕业）
