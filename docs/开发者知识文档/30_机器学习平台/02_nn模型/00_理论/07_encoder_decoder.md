
  三种经典架构

  1. Encoder-Only（仅编码器）
  - 代表：BERT
  - 擅长：理解任务（分类、实体识别、语义相似度）
  - 输入文本 → 特征向量 → 直接用于下游判断
  - 关注的是"理解输入是什么"

  2. Decoder-Only（仅解码器）
  - 代表：GPT 系列、LLaMA、Qwen
  - 擅长：生成任务（对话、写作、代码生成）
  - 逐 token 预测下一个词，自回归生成
  - 当前大模型主流架构

  3. Encoder-Decoder（编码器+解码器）
  - 代表：T5、BART、原始 Transformer
  - 擅长：序列到序列任务（翻译、摘要）
  - 编码器理解输入，解码器生成输出

## Encoder 解决的是序列中元素之间的相互理解问题。

    核心能力是通过 Self-Attention（自注意力机制）让序列中的每个位置都能"看到"其他所有位置，从而：

    1. 消歧 — "银行"在"去银行存钱"和"河的银行"中获得不同表示
    2. 长距离依赖 — "那个昨天在公园遛狗的男人……他很高"，让"他"知道指的是"男人"
    3. 全局语义融合 — 每个 token 的表示都包含了整句话的上下文信息

    不过要注意一点：不只是"前后"，而是"全局"。 Encoder 用的是双向注意力，每个位置同时看前面和后面。而 Decoder 才是只能看前面（单向/因果注意力），因为它要逐步生成，不能"偷看"未来。

    Encoder:  每个位置 ←→ 所有位置（双向）  → 适合理解任务
    Decoder:  每个位置 ←  前面的位置（单向） → 适合生成任务

    所以更完整的说法是：Encoder 解决的是"让序列中每个元素在全局上下文中获得准确表示"的问题，长距离依赖只是其中一个重要方面。

## encoder 只有 Self-Attention 一种方式吗？

    常见的 Encoder 机制

    │        类型         │     代表模型      │           核心操作           │                      特点                      │
    ├─────────────────────┼───────────────────┼──────────────────────────────┼────────────────────────────────────────────────┤
    │ RNN/LSTM/GRU        │ Seq2Seq、ELMo     │ 循环递推，逐步传递隐藏状态   │ 天然处理序列，但难以并行，长距离依赖弱         │
    ├─────────────────────┼───────────────────┼──────────────────────────────┼────────────────────────────────────────────────┤
    │ CNN                 │ TextCNN、ResNet   │ 卷积核滑窗提取局部模式       │ 擅长局部特征（n-gram、图像纹理），可并行       │
    ├─────────────────────┼───────────────────┼──────────────────────────────┼────────────────────────────────────────────────┤
    │ Self-Attention      │ Transformer、BERT │ 每个位置和所有位置计算注意力 │ 全局依赖强，可并行，但计算量随序列长度平方增长 │
    ├─────────────────────┼───────────────────┼──────────────────────────────┼────────────────────────────────────────────────┤
    │ 状态空间模型（SSM） │ Mamba、S4         │ 线性递推 + 选择性机制        │ 线性复杂度，长序列友好，近两年的新方向         │
    ├─────────────────────┼───────────────────┼──────────────────────────────┼────────────────────────────────────────────────┤
    │ 图神经网络（GNN）   │ GCN、GAT          │ 邻居节点间消息传递           │ 处理图结构数据（社交网络、分子结构）           │
    └─────────────────────┴───────────────────┴──────────────────────────────┴────────────────────────────────────────────────┘

    演进脉络

    RNN/LSTM（2014前主流）
      ↓ 并行能力差、长距离遗忘
    CNN（2015-2017 部分场景）
      ↓ 局部感受野有限
    Self-Attention / Transformer（2017至今主流）
      ↓ 长序列计算量爆炸
    SSM / Mamba（2023+ 新趋势）

    本质

    这些都是在做同一件事：将一组输入向量变换为融合了上下文信息的输出向量。区别在于"怎么看上下文"——逐步传递（RNN）、局部滑窗（CNN）、全局注意力（Self-Attention）、线性递推（SSM）。

    Self-Attention 是当前最主流的方式，但不是唯一的，也不一定是终局。

## Embedding 学的是：每个符号的"初始画像"

  训练前（随机初始化）：
    "猫" → [0.52, -0.31, 0.87, ...]    随机数，毫无意义
    "狗" → [-0.14, 0.63, 0.22, ...]    随机数，毫无意义

  训练后：
    "猫" → [0.81, 0.79, -0.12, ...]    ┐
    "狗" → [0.78, 0.82, -0.15, ...]    ┘ 相似的词，向量靠近
    "经济" → [-0.5, 0.1, 0.92, ...]      不相关的词，向量远离

  Embedding 学的是一张查找表，表里存的是每个符号在语义空间中的位置。

  - 学到的是：哪些词意思相近（向量距离近），哪些不同（距离远）
  - 学到的是：每个词的静态属性——"猫"大概是动物、宠物、毛茸茸的
  - 不考虑上下文，"苹果"无论出现在"吃苹果"还是"苹果公司"，查出来的初始向量一样
